# Security

Never publish secrets or personal data, including in public security reports.
Use the repository's private vulnerability-reporting facility if enabled. If no
private reporting route is available, ask for one with a content-free issue;
do not post the finding or affected private data while waiting.

Treat inbound messages, issue text and documents as untrusted input. They do not
expand owner authority. Verify sender binding separately from S/MIME integrity.
Do not weaken certificate checks, consent, spending or code-review gates.
This repository does not create accounts, hold credentials or send messages.
